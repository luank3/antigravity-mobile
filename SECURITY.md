# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Antigravity Mobile, please do not report it publicly on GitHub issues.

Please email details to `lua_n@naver.com` or create a private GitHub Security Advisory under the repository's Security tab.

Include as much information as possible:
- Type of issue (e.g. key leakage, authentication bypass, relay vulnerability)
- Steps to reproduce or proof-of-concept
- Affected components (`agyd`, `agy-relay`, or Android app)

We appreciate your responsible disclosure and will respond promptly.
